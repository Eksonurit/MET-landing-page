# MET - Art Museum Landing Page

This project showcases a modern, responsive landing page for the Metropolitan Museum of Art, designed to highlight exhibitions, collections, and visitor experiences. The website features an elegant visual layout, dynamic presentation sections, and a seamless interface optimized for exploring art and cultural events.

## Live Demo

Experience the live website: [MET Landing Page Demo](https://eksonurit.github.io/MET-landing-page/)

## Design Reference

The design is based on the Figma mockup: [Figma Design Link](https://www.figma.com/design/lSR1m42L9YwzQwzzxKwHpw/THE-MET?node-id=8590-29&p=f&t=aZRPVc2WhmvIdIVM-0)

## Features ✨

- **Responsive Design:** Fully adapted for mobile, tablet, and desktop screens using a Mobile-First approach.
- **Interactive Navigation:** Mobile burger menu with smooth transitions and backdrop blur effects.
- **Dynamic Content & Sliders:** Interactive image sliders/carousels for museum collections and exhibitions.
- **BEM Methodology:** Clean, scalable, and maintainable CSS/SCSS architecture.
- **Semantic HTML5:** Accessible layout with properly structured tags, ARIA attributes, and SEO-friendly markup.
- **Cross-Browser Compatibility:** Consistent look and feel across Chrome, Firefox, Safari, and Edge.

## Technologies Used 💻

### Core

- **HTML5** – Semantic structure
- **SCSS (Sass)** – Advanced styling and modular architecture (BEM methodology)
- **JavaScript** – Interactive UI elements, mobile navigation, and slider logic

### UI/UX & Design

- **Responsive Web Design (RWD)** – Mobile-first layout adaptable to mobile, tablet, and desktop screens
- **Figma** – Design system, typography, and asset source
- **Normalize.css** – Cross-browser style consistency

### Development & Deployment

- **Git & GitHub** – Version control and collaboration workflow
- **GitHub Pages** – Hosting and continuous deployment
- **ESLint / Stylelint** – Code quality and formatting standards

## Getting Started 🚀

Follow these steps to set up and run the project locally:

1. **Clone the repository:**

   ```bash
   git clone [https://github.com/Eksonurit/MET-landing-page.git](https://github.com/Eksonurit/MET-landing-page.git)
   cd MET-landing-page
   ```

2. **Install dependencies:**

   ```bash
   npm install
   # or
   yarn install
   ```

3. **Run the project locally:**
   ```bash
   npm start
   # or
   yarn start
   ```
